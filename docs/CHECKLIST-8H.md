# 给 Rowan 的验收清单（8 小时成果 · 十分钟版）

> 怎么用：先到项目目录（就这一条固定路径）：
>
>     cd "/Volumes/Mac mini/Max agent/Sammy"
>
> 每条都写清楚「跑什么 / 你会看到什么 / 怎么算过」。任何一条不过，把输出发我，我来查。

## 0. 一分钟总检（先跑这个）

- [ ] `make check` —— 离线全量自检（测试 + 代码风格 + 凭证审计）。
  - 你会看到：进度条走满、没有 FAILED；ruff 那行是 All checks passed 的字样。
  - 算过：全绿无红字（退出码为零）。

## 1. 心情（T1）

- [ ] `make mood` —— 看它此刻的底色。
  - 你会看到：「心情：平静（+0.15）」这类一行，加上次更新时间和空闲会摆的脸。
  - 想看它动：`make run` 跑起来戳它几下，过一会儿再 `make mood`，数字会跟着变。
  - 算过：心情值在 -1 到 +1 之间；戳过之后明显变化。

## 2. 回忆（T2）

- [ ] `make recall` —— 看它会不会想起旧事。
  - 你会看到：候选旧事列表（现在 6 条）、三条闸门的状态、以及「如果现在开口会说什么」。
  - 算过：地址 / 健康 / 凭证类内容不在候选里；给出的话术像人想起来的，不是念档案。

## 3. 小屏脸（T3）

- [ ] `make face-only` —— 全屏小屏形态（脸 + 一行状态）。
  - 退出：另开一个终端跑 `bash scripts/stop_sammy.sh`（在窗口上按 Ctrl+C 不一定灵）。
  - 你会看到：铺满屏的一张脸；跟它说句话，那行字先变「刚说的话」。
  - 不想全屏打扰：看 `docs/8h/faceonly-1024x768.png` 就行。
  - 算过：脸明显比完整版大；屏上没有输入框、没有回复区。

## 4. 看门狗（T4）

- [ ] `make watchdog-demo` —— 全流程演示（约一分钟，全落在 .tmp/，不碰真实数据）。
  - 你会看到：崩溃循环按 3/6/12/24 秒退避拉起、留下 5 份崩溃日志、然后放弃（退 4）；
    另外两条路径：正常退出不复活、真 Sammy 被 TERM 收得干净。
  - [ ] 真机挂一次：`make watchdog`（Ctrl+C 收工）；另开终端 `make watchdog-status`。
  - 算过：演示三行全 ✅；status 能说出在不在盯。

## 5. MCP（T5 + 后续块）

- [ ] `make mcp-demo` —— 四条链路（离线、真子进程）。
  - 你会看到：假 server 现代协议通、自家工具挂成服务通、挂进工具表再调通、换目录无 PYTHONPATH 启动照通（第 ④ 条）。
  - 算过：四行全 ✅、每次调用的耗时可读（0.0x 秒）。
- [ ] `make mcp` —— 看配置状态（没配的话它会把三步教你）。
- [ ] 双击 `dist/Sammy.app`（10-11 07:07 重建，已带本轮全部内容）。
  - 你会看到：窗口直接出现（不需要终端）。
  - 算过：能起、能对话；打包版的 MCP 配置写法与源码版完全相同。

## 6. 报告与素材（T6）

- [ ] `make report-media` —— 重生成报告素材（截图 + 短片，都进 docs/8h/）。
  - 算过：五件文件名都在；输出里带尺寸和「亮像素点」数字。
- [ ] 花三分钟看一遍 `docs/REPORT-8H.md` —— 本轮总结，含图片、数字、待拍板清单。

- [ ] 想调一个数（脸的大小 / 脾气 / 回忆频率 / 看门狗阈值 / MCP 默认开不开）：照 docs/TUNING.md 改。
  - 你会看到：6 个拍板点各自对应哪个文件、哪个常量、现在多少，一页看完。
  - 算过：改完跑 make check 全绿（那页的值本身也被测试对账）。

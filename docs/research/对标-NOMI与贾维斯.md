## 一、NOMI 到底是什么（查证后的事实）

### 定位

NOMI 取自 **Know Me** 谐音，蔚来官方定位是 **"懂你的情感伙伴"**，三个特性：**自然拟人交互 / 贴心可靠帮手 / 专属情感伙伴**。媒体报道里普遍拿科幻电影《Her》来类比 —— 蔚来自己也不否认这个野心。

**关键：NOMI 从来就不是"车载语音助手"。** 它是车的脸和人格。这跟我们要做的东西是同一件事。

### 硬件形态

| 项 | 事实 |
|:---|:---|
| 屏幕 | NOMI Mate 是**首个车内全圆 AMOLED 屏**，对比度 100000:1，2.5D 曲面玻璃，接近 **180° 可视角度**（主驾副驾都能看清） |
| 头部 | **可物理掰动**；Banyan 3.0 版本达到 **340° 超大摇摆幅度** |
| 表情 | "超多的表情包"，各种场景都有丰富情感表达；另有"灵动视窗"做信息展示 |
| 声音 | 由**给迪士尼、梦工厂动画配音的团队**打造；第四代神经网络，与真人录音还原度 >98%；**能通过声音表达开心、严肃、委屈、可爱等情绪** |

### 交互能力（这部分是我们最该抄的）

| 能力 | 说明 | 对 Sammy 的意义 |
|:---|:---|:---|
| **语音免唤醒** | 不用每次喊名字，直接说 | 我们现在是"打字 + 回车"，差得远 |
| **多人自由说** | 多音区的人可以同时对话 | 需要麦克风阵列 + 声源分离 |
| **多音区识别** | 主驾/副驾/后排可独立唤醒，系统**区分声音来源**并执行对应操作 | 对应"转头看向说话的人" → 舵机 pan/tilt |
| **声纹识别** | **能精准识别不同用户的声音** | Rowan 已批准：可以做 |
| **一句话多指令** | 一句话说多个需求，按序执行 | 意图解析要支持多任务 |
| **精准执行** | 能执行"**开 20% 的窗**"这种带数值的指令 | 工具调用必须支持参数，不是开/关 |
| **拟人反馈动作** | 接收指令后**点头、摇头、转头**给予反馈 | 表情必须和舵机动作耦合 |

### 能力与主动性

- **控制整车核心域**：车窗、空调、座椅（加热/通风/按摩）、氛围灯、多媒体、导航、后视镜、遮阳帘、后备箱
- **主动智能**：Banyan 3.0 引入 **NOMI Agents 多智能体架构**，明确的目标是"从**单点功能**向**主动智能**进化"
- 体量：NOMI 已迭代 **130+ 个版本、2000+ 项功能**；NOMI GPT 上线 3 个月内交互超 1500 万次
- 也坦白"不知道""还在学习" —— 不会硬编答案

### 两个特别有意思的设计

1. **AI 帽子**：物理帽子 + 智能芯片 → 刷一下解锁**专属登场秀、应答语、趣味表情、特别技能**。本质是**用物理配件换人格皮肤**。
2. **互动玩法**：和用户猜拳（摄像头识别手势 + 头部摆动 + 语音表情公布胜负）、**跟随音乐节奏摇摆**当车载 DJ、给小孩讲故事。

## 二、贾维斯那半边：能力与主动性

Rowan 的原话是"**或者是桌面版的贾维斯**"。贾维斯的定义大家都懂：**能理解、能调度、能预判、有性格的全能管家**。

开源实现里最接近的是 `LYiHub/pub-local-jarvis`，它的功能表基本就是"桌面版贾维斯"的最小可行清单：

| 能力 | 做法 |
|:---|:---|
| **桌面陪伴** | 结合**实时屏幕 + 系统声音**理解当前场景，在合适时机给简短提醒或点评 |
| **主动对话** | 快捷键唤起对话框，直接问；会**结合实时画面**回答 |
| **游戏陪伴** | 识别实时游戏场景，用**不干扰操作的透明弹幕**给提示 |
| **网课记录** | 课中提醒，课后自动生成含**关键画面 + 知识点**的 Markdown 笔记 |
| **本地记忆** | 从场景感知结果整理**活动时间线 + 每日总结** |
| **隐私原则** | ⭐ **原始屏幕画面和音频不写入长期记忆** |
| **隐私模式** | 双击桌宠即可暂停/恢复屏幕与音频感知，暂停后模型拿不到画面和声音 |

配套的现成零件（都在生态里，而且是 MCP 形态）：
- `gaze` —— 轻量连续屏幕感知：抓前台窗口 → 生成视觉描述 + OCR → 写滚动 JSON 上下文
- `cove-sensory-mcp` —— **本地 stdio MCP 感官层，给纯文本大模型装上眼睛和耳朵**（图像/视频/音频/音乐路由到多模态服务，带严格隐私沙箱）

## 四、从对标提炼出的 8 条产品原则

1. **它先开口。** NOMI 的进化方向是"从单点功能到主动智能"。被动应答的助手永远是工具，会主动的才是伙伴。
2. **说完要"应一声"。** NOMI 用点头/摇头/转头确认收到了 —— 屏幕上换表情不够，物理动作才是"它在听"的证据。
3. **不用每次都喊名字。** 免唤醒是"自然"的分界线。
4. **记得住是谁在说话。** 声纹 + 多用户档案，是从"它"变成"你"的关键。
5. **精准比聪明更重要。** "开 20% 的窗"比"开窗"难得多，但用户会因此信任它。
6. **人格是可以换装的。** AI 帽子证明了：**用户愿意为"性格"付钱和动手**。我们的数字版是"人格包"。
7. **原始感知数据不进长期记忆。** 学贾维斯：感知结果可以进记忆，原始画面/音频不行。而且要有**一键暂停感知**的开关。
8. **答不上来就承认。** NOMI 会说"不知道""还在学习" —— 别硬编。

## 五、硬件影响（重要）

对标 NOMI 的"转头看向说话的人"，**现在那份 ¥400 的 BOM 不够**：

| 需要补的 | 为什么 | 大致成本 |
|:---|:---|:---|
| **麦克风阵列**（2~4 麦） | 单麦克风测不出声源方向，"转头看人"做不了；多音区也做不了 | 旧 BOM 五期里已列过（远场拾音，+¥80） |
| **麦克风阵列 + 声源定位算法** | 方向估计（DOA） | 软件，用现成算法 |
| 摄像头（三期已列） | 猜拳手势识别、人脸追踪 | +¥100（已列） |

**结论：硬件 BOM 要提前把麦克风阵列从"五期"提到"二期"。** 否则"NOMI 式转头"永远做不出来。

## 六、一句话总结

**NOMI 证明了这条路走得通 —— 它不是"更好的语音助手"，它是车的脸和人格，而且用户真的会为一个有情绪的屏幕上瘾。贾维斯证明了能力侧的边界可以很宽 —— 但它要求"能看见、能听见、能调度"。**

Sammy 就是这两者的桌面版：**一张会发光的脸、一副会动的身体、一双看得见屏幕的眼睛、一堆接得上生态的手。**

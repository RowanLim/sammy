# UI 调研：GitHub 上值得二次开发的（2026-10-11）

Rowan 原话：「优先修改 ui 你可以在 GitHub 上看看有没有什么值得二次开发的」。
下面三条是我实际查到的，**按"能怎么用"分类** —— 许可证决定了能不能抄代码，这一点必须先看清。

## ① 缝合像素字体 / Fusion Pixel Font ✅ **直接采用**

- 仓库：`TakWolf/fusion-pixel-font`（3.2k★，OFL-1.1 + MIT）
- 是什么：**泛中日韩像素字体**，8/10/12 像素三档，有 zh-Hans / zh-Hant / ja / ko 字形版本，
  等宽与比例两种模式。上游是「方舟像素字体」，与一堆同尺寸字体"缝合"而成，故名。
- 为什么值得用：**我们整个界面是像素风格，字却是系统矢量字体** —— 状态行、对话、输入框
  全是抗锯齿的现代字。这是当前"看着不像一台老机器"的最大来源。
- 许可：**OFL-1.1** → 可以随项目分发（要带上许可证与出处）✅
- 具体怎么用：12 像素档 + 比例模式 + zh-Hans，**按整数倍放大**（12px × 2 = 24 设备单位，
  正好落在我们 22~30 的字号区间）→ 像素不糊。
  字体包 ~48MB（全 CJK），所以**必须做子集**：GB2312 全字集 + ASCII + 中文标点 ≈ 日常文本 99.9%
  （剩下的字仍会回落到系统字体，不会变方块）。

## ② RoboEyes（FluxGarage）🟡 **只借想法，不抄代码**

- 仓库：`FluxGarage/RoboEyes`（672★，**GPL-3.0**）
- 是什么：Arduino 上给 OLED 画"会动会表情的机器人眼睛"的库：眼睛形状可调（宽/高/圆角/间距）、
  情绪（累 / 生气 / 开心 / 默认）、以及 idle 模式（眼球每隔几秒随机看向别处）、
  自动眨眼、好奇（看向边缘时眼睛变高）、出汗、笑到抖、困惑抖。
- **许可证是 GPL-3.0**：代码不能抄进我们的项目（那是病毒式许可），
  但**它验证了哪些动效让人"觉得活"**，这些想法可以自己实现 ✅
- 我们要借的三条想法（都是新的实现，不是移植）：
  1. **idle 凝视漂移**：每几秒看向随机方向（我们现在只有眨眼/呼吸/微动，眼睛是不动的）；
  2. **好奇**：看向左右边缘时眼睛变高一点；
  3. **过渡要 tween**：情绪切换是缓动过去的，不是瞬间跳（我们现在只有一个 0.22s 的"弹一下"）。

## ③ Open-LLM-VTuber 🟡 **交互参考（也是想法层）**

- 仓库：`Open-LLM-VTuber/Open-LLM-VTuber`（Live2D + LLM 陪伴，桌面宠物模式）
- 值得抄的**交互**（实现要自己写）：
  1. **桌宠模式**：透明背景 + 置顶 + **可点穿区域**（不挡用户操作）—— 我们的桌面浮窗已经接近；
  2. **语音打断**：说话时被打断能立刻停 —— 我们已实现（新回复掐掉正在念的）；
  3. **按句切分送 TTS**：一句一句念，首句先出声（降低等待感）；
  4. 情绪映射：后端给情绪标签 → 前面换表情 —— 我们已经有（表情编号）✅

## 结论：这一轮 UI 优先事项

| ID | 做什么 | 依据 |
|---|---|---|
| U1 | **换像素字体**（OFL，子集化后随仓库分发） | ① |
| U2 | **face-only 小屏形态**（只留脸 + 一行状态，适配 4:3） | 昨天与 Rowan 讨论的复古壳方案 |
| U3 | **凝视漂移 + 好奇 + 缓动过渡**（自己实现） | ② 的三条想法 |
| U4 | **打字机显示 + 思考指示**（回复逐字出现） | ③ 的"降低等待感"思路 |
| U5 | **CRT 质感**（扫描线/辉光，可关） | 配合复古壳的审美 |
| U6 | 收尾：前后对比图 + 短视频 + 一页验收清单 | — |

非 UI 的（回忆主动性 / 看门狗 / MCP）**排在 UI 之后**，等这轮 UI 收完再回去做。

# 给 Rowan 的验收清单（第二轮 UI 成果 · 十分钟版）

> 怎么用：先到项目目录（就这一条固定路径）：
>
>     cd "/Volumes/Mac mini/Max agent/Sammy"
>
> 每条都写清楚「跑什么 / 你会看到什么 / 怎么算过」。任何一条不过，把输出发我，我来查。
> 这一轮只动界面：字（U1）、脸（U2）、话（U3）、质感（U4），收尾与素材在这页（U5）。
> 素材三件套在 docs/8h-b2/ 里，Gitea 网页上可以直接点开。

## 0. 一分钟总检（先跑这个）

- [ ] `make check` —— 离线全量自检（测试 + 代码风格 + 凭证审计）。
  - 你会看到：进度条走满、没有 FAILED；ruff 那行是 All checks passed 的字样。
  - 算过：全绿无红字（退出码为零）。
- [ ] `make ui-media` —— 重生成这一轮的素材（对比图 + 短视频，进 docs/8h-b2/）。
  - 你会看到：几行 ok（整窗素材、两张对比图、视频的帧数与秒数）。
  - 算过：docs/8h-b2/ 下的三件套都在，mp4 约 15 秒。

## 1. 像素字体（U1）

- [ ] `make run` 起来，看状态行 / 你的输入框 / 它的回复。
  - 你会看到：全都是像素字（点阵感、笔画落在网格上）；中文、英文、标点都齐、没有方块。
  - 算过：凑近看字缘是硬的，不是抗锯齿的灰边。
- [ ] 或者看 [before-after-zoom.png](8h-b2/before-after-zoom.png)（文字区 2 倍放大，左旧右新）。
- 字体不在也不会变成没字：回落系统字体并在启动输出里说明（原因与许可证都在 assets/fonts/）。

## 2. 脸会看（U2）

- [ ] `make run`，盯着脸看 30 秒。
  - 你会看到：每隔几秒缓动看向一个新的方向，然后**看定**；看向左右边缘时脸会向上探一点（好奇）。
  - 算过：一分钟里能数出 8~23 次转向（平均十来次）；没有瞬移。
- [ ] 换表情看过渡：逗它开心、或者敲它一下换脸 —— 表情是**淡过去的**，不是啪地切断。
- [ ] 大脸版再看一遍：`make face-only`（复古壳那台小屏的形态，脸是完整版的约 1.5 倍）。

## 3. 话是打出来的（U3）

- [ ] `make run`，随便发一句话。
  - 你会看到：等模型时回复区有三个大点在长（正文行是小点）；回答一到，**一个字一个字**打出来。
  - 算过：速度约 25 字/秒；整页最多打 4.5 秒，太长会整体加速（打字机不逼你多等）。
- [ ] 同一句回复等到翻页看第二遍：第二遍起是**整页直接给**，不再一个字一个字重放。
- [ ] 抓图永远是一整句：`./run.sh --snapshot .tmp/snap.png --reply "随便来一句"`。

## 4. CRT 质感（U4）

- [ ] `./run.sh` 默认就是开着的：凑近看有**隔行扫描线**、四角略暗、亮的地方有一层荧光。
- [ ] 关掉对比：`SAMMY_CRT=off ./run.sh`；或看 [before-after.png](8h-b2/before-after.png) 的第 2、3 格。
- 算过：扫描线 / 暗角 / 辉光的数字都被测试钉着（test_crt.py 15 条）；关掉时与加它之前**逐像素一致**。

## 5. 请你拍板的 6 个审美点（他拍板，我执行）

> 每个点给出现值、藏着的位置、往哪调是什么效果。细目都在 docs/TUNING.md 第 7~11 节；
> 你只要说「第几点、往哪边调」，我来执行，改完跑 make check 全绿再提交。

1. **① 像素字的整体观感** —— Sammy Pixel（Fusion Pixel 的 12px 子集），正文与输入 24 号、回复区从 36 号往下试。
   - 想更大、想更小、或换另一种像素字：都只动 layout.py 一处。
2. **② 打字机的节奏** —— 每字 40 毫秒、标点后多停 90 毫秒、整页超过 4.5 秒整体加速。
   - 觉得拖或急：先动 typewriter.py 的 TYPE_CPS 一个数（现在是 25 字/秒）。
3. **③ 思考点的样子** —— 回复区大点、正文行小点，每 0.4 秒一帧、一颗长到三颗循环。
   - 想换别的等待表达（方波、呼吸灯之类）：说一声我来换，判据我这边是齐的。
4. **④ 凝视漂移的活跃度** —— 每 2.6~7.4 秒换方向、幅度 ±10/±6、0.55 秒缓动然后定格。
   - 觉得太活泼：拉长间隔、收小幅度（anim.py 的 GAZE_ 开头四个常量）。
5. **⑤ 好奇与换脸的表达** —— 贴边纵向拉高最多 7%（好奇）；换表情 0.38 秒交叉淡化，另保留 0.22 秒的「弹一下」。
   - 嫌夸张就减 CURIOSITY_STRETCH；嫌黏就减 FADE_DURATION（两者都可以做到几乎无感）。
6. **⑥ CRT 的强度与默认** —— 扫描线 0.15 / 暗角 0.30 / 辉光 0.40；默认开，`SAMMY_CRT=off` 可关。
   - 想淡一点先动 SCANLINE_ALPHA 和 VIGNETTE_ALPHA（crt.py）；嫌费电也可以默认关。

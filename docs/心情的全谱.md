# 心情的全谱（自选小步·第二十八次）

## 为什么做这件

现在的 `mood.py` 只用一个数（`valence`）说心情，分五档：
低落 / 有点蔫 / 平静 / 不错 / 很好。

问题是**只有一根轴**。这一根轴能表达「今天过得好不好」，
表达不了「今天过得热闹还是冷清」。而这两件事对一张脸的影响是不同的：

- 过得**好**：嘴角该往上走（好心情）。
- 过得**冷清**（一直没人理、也没发生什么事）：眼神该发飘、脑袋该放空（走神）。

更要紧的是**推它的东西只有两类**：别人说的话 / 被戳一下。
于是「没人理」这个输入只能踩刹车（往下走），**从来不会推动它做任何事**。
最需要一个「活物」的样子的时候（你不在），它反而最没事可干 ——
这跟 TUNING 里已有的一批「只在有人时才看得到」的活物迹象是同一个毛病。

所以这一步加**第二根轴**，而不是改 `valence` 本身。

## 定下来的口径

| 项 | 决定 | 为什么不选另一头 |
|---|---|---|
| 第二根轴叫什么 | **劲头**（`spirit`，±1，0 = 平常） | 不叫「唤醒度」：那是心理学词，给后来人看的人话优先（与 `label_of` 的「说人话」同一条规矩） |
| 两根轴怎么记 | **还是只存一个数在 `mood.json`** —— 劲头从 `valence` 与最近发生的事**算出来**，不新增落盘字段 | 多一个要迁移的字段就多一类「文件坏了/旧文件读不出」的故障面；算出来的东西永远不会和已有的数打架 |
| 谁让劲头上去 | 「有趣/热闹」的表情（大笑、搞怪、新奇、期待、星星眼…）与被逗一下 | 「平静的开心」（微笑）不算热闹 —— 那样它就一直在高位，等于常量 |
| 谁让劲头下来 | 「没精神/蔫」的表情（困、睡着、打哈欠） | 负面情绪不算冷清：难过是**往下**那根轴的事，不是**没劲**那根轴的事，两根轴不该互相代理 |
| 没人理的时候 | 超过 3 小时后慢慢往下（与 `alone_drift` 同一道闸门、同一个速率量级） | 再开一套时间常数就是两套作息，容易打架 |
| 它不能干什么 | **不许反过来改 `valence`、不许改 `idle_expression`** | 那会动到已有的判据（心情钉死的默认表情、紧缩姿态），等于拿审美赌稳定性 |

## 两根轴合起来才是一个「谱」（这次真正要落地的东西）

一根轴只能切段；两根轴才能**说人话地命名状态**，而且顺带能钉住一件事：
**负面格子不许说出好听的话**（这是陪伴产品的反面教材）。

| 劲头 ＼ 好坏 | 低落 | 有点蔫 | 平静 | 不错 | 很好 |
|---|---|---|---|---|---|
| **兴奋** | 心里堵得慌 | 有点坐不住 | 有点躁 | 挺来劲的 | 兴致很高 |
| **偏活** | 提不起劲 | 有点闷 | 挺有兴致 | 挺来劲的 | 兴致很高 |
| **平常** | 低落 | 有点蔫 | 还行 | 挺轻松 | 心情挺好 |
| **偏蔫** | 提不起劲 | 有点闷 | 有点走神 | 有点懒懒的 | 静静的满足 |
| **走神** | 空落落的 | 发蔫 | 放空 | 悠着 | 安安静静地高兴 |

两处特别标出来的：
- 「**心情挺好**」：`valence = HOME`（0.15）在只有一根轴的时候被叫「平静」——
  这不对，基线是**略偏正面**的（它本来就是个乐乎的性子）。
  分档边界一个字没改（怕动到别的判据），是**名字**跟着两根轴细化了。
- 规则：`valence < -0.05` 且 `spirit < 0` 的格子，名字里**不许出现**「不错/挺好/满足」这类词 ——
  判据要扫的正是这条。

## 两个可以先说清楚的坑

1. **「兴奋 + 低落」不是 bug，是真实存在的一格**（心里堵得慌）。
   第一反应可能是把它压掉（「不高兴的人不该有劲」），但**压掉它才是假的**：
   这格恰恰是最需要它**不闹**的时候（提示词里要写「别亢奋、别安慰成鸡汤」）。
   所以判据钉的是「这一格存在、且提示词里带『不闹』」，不是「这一格不存在」。
2. **别把 `label()` 换掉**。`describe()`（`--mood` 打印的那个）才用全谱的名字；
   `label()` 保持短档位名 —— 它在 `pet.py` 与多份判据里被读，换了就是无声改口径。
   同理 `prompt_line` 的既有那一行（`你今天的心情：平静（平常心就行）`）**一字不动**，
   劲头只作为**另一句**接在后面。

## 判据打算钉什么（都打在纯函数上，离线可跑）

- 两轴都夹在 ±1 且落盘只有一个数（`mood.json` 的键不变）；
- 有趣的表情提劲头、困/睡的表情降劲头、中性表情不动；
- 「平静的开心」不算热闹（微笑不该把劲头推上去）；
- 独处超过闸门才降，且**有地板**；
- 谱是**满的**：5 × 5 每格都有名字，没有空格与洞；
- 负面格子不许出现好词（规则扫全表，不是手抄一份对照）；
- 两根轴**互不代理**：推劲头不许改 `valence`；绷到两头时 `idle_expression` 与原来一字不差；
- 提示词：`prompt_line` 的既有那行逐字不变，劲头是后面接的**一句**，且只在两端（`|spirit| ≥ 0.5`）才出现。

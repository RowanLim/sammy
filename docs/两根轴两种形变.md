# 两根轴，两种形变（自选小步·第二十九次）

## 为什么做这件

第二十八次给心情加了第二根轴（劲头 spirit），但它**只改了名字**：
`mood.json` 里还是只有一个数，说人话的格子只出现在 `--mood` 那一行和提示词那一句。
换句话说：一个「走神」的 Sammy 和一个「挺来劲」的 Sammy，**静止时的姿态逐像素相同**。

这正是 `docs/心情的全谱.md` 自己点名的毛病：
**这批活物迹象只在有人时才看得到**。你不在的时候它最该像个活物，反而一点变化都没有。

## 定下来的口径

| 项 | 决定 | 为什么不选另一头 |
|---|---|---|
| 第二根轴落在哪 | **静止姿态的纵向一档**（`anim.spirit_posture`） | 不并进 `mood_shrink`：并进去两根轴就互相代理，「低落 + 兴奋」那格会被算成反而更小，与全谱口径打架 |
| 两种形变的区别 | 心情低 = **小一号**（宽高一起缩）；劲头低 = **塌一点**（只压纵向） | 「没劲」是塌下去，不是变小。两种形变分得开，才看得出是哪根轴在动 |
| 门线 | **正负 0.15**（与 `mood.SPIRIT_MILD_DOWN/UP` 同一条） | 另立一把尺就有两套口径，迟早不一致 |
| 塌到底 | 纵向 **97.5%**（`SPIRIT_POSTURE_SINK_MIN`） | 比 `MOOD_SHRINK_MIN`（94%）浅 —— 塌不该比缩还抢戏 |
| 提多少 | 最多 **+2.5%**（`SPIRIT_POSTURE_LIFT_MAX`） | 只有塌的一半：高的一头是加分，不该比低的一头更抢眼 |
| 闸门 | **和 `mood_shrink` 同一道**（动画关 / 睡着回 1.0，`mood.posture_for`） | 另立一条闸门 = 又多一处会和 `shrink_for` 不一致的地方 |

## 两根轴互不代理，怎么钉的

这是这一条的**核心判据**。三件事分开测：

1. **`mood_shrink` 逐值未变**：给劲头喂任何值，心情那根轴的返回值一字不动；
2. **只在 `stretch` 上乘一档**：同一条时间线上，喂过的它 / 没喂的它，
   `stretch` 恰好差一个比例，而 `shrink` / `squash` / `pop` / 凝视 / 位移**逐值相同**；
3. **默认逐像素不变**：没喂过时 `spirit_posture(0.0) == 1.0`，等于加这根轴之前。

## 判据（11 条，`tests/test_spirit_posture.py`）

四层：

- **纯函数**：量级守卫、门线以内恒 1.0（含 0 点与门线本身）、两头单调、两头截断、确定性；
- **不许代理**：见上一节第 1/2/3 条；
- **落点**：只在纵向那一路，别的通道逐值不动；
- **闸门**：动画关 / 睡着回 1.0，与 `mood_shrink` 走同一个 `posture_for`。

# 凭证总目录 · CREDENTIALS-INVENTORY

> 凭证的唯一合法位置是 项目 data 目录下的 .env —— 它在项目里且被 git 忽略，所以不会进版本库，也不会被打进打包后的 app 里。
> 这份文件是位置台账，不是保险箱：里面一个密钥字符都没有，
> 只写清哪台机器、哪个路径、什么类型。密钥原文永远只留在它自己的文件里。
>
> 台账的意义是把多出来的位置变成看得见的东西；看不见的凭证才是漏点。
>
> 扫描命令是 .venv/bin/python scripts/credential_sweep.py，只读、只报位置、不打印内容。
> 台账与扫描结果由 tests/test_credentials_inventory.py 逐条对账。

## 一、台账

| # | 位置 | 里面是什么（类型或前缀，不含密钥原文） | 处置 |
|---|---|---|---|
| 0（合法） | `项目 data/.env` | SAMMY_CHAT_API_KEY / SAMMY_AGENT_API_KEY / SAMMY_TTS | 唯一的家：被 git 忽略、不进打包的 app |
| 1 | `~/.hermes/.env` | DEEPSEEK_API_KEY 等 3 处值 | Hermes 自己的配置；扫描只报一条，因为它逐行只认一个规则 |
| 2 | `~/.hermes/.env` | DEEPSEEK_API_KEY 重复定义（相邻两行同值） | 清理候选：同一键写两遍 |
| 3 | `~/.hermes/.env` 第 477 行 | DASHSCOPE_API_KEY（35 字符） | 项目代码里零引用 —— 要不要留由 Rowan 定 |
| 4 | `~/.hermes/remote-keys` | Nex 与本机的 API key | 跨机器密钥，必须留；只登记目录名，不点名到文件（目录没有行号） |
| 5 | `~/.gitconfig` | http(s).proxy=127.0.0.1:12000 | 不是凭证，但代理死了所有 git 报 connect refused |

## 二、三条纪律

1. 项目里只认 data 目录下的 .env 这一处。多出一个位置就该红。要么搬回那一处，要么在台账里登记并写清为什么它必须在那儿。
2. 扫描器只读：不删、不改、不挪；命中了只输出文件、行号与规则代号。
3. 机器级的位置只列名字、不递归：那是 Rowan 的地盘，不是替他去整理。

## 三、一眼看得到的结论

- 项目本身是零泄漏：data 目录下的 .env 之外一处都没有，183 个文件全扫过。
- 项目的数据目录里没有任何凭证，这是隔离约定的直接后果，不是巧合。
- 机器级那三处不属于本项目，但压测与调试时会顺手用到，所以列在这里。

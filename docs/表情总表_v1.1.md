## 0. 通用定义（先读这一节，后面所有表共用）

**列含义**

- **触发场景**：什么事件让这个表情出现。两参考仓库是纯技术实现、没有定义产品场景，凡是我们补的场景映射都带 [自定]。
- **眼型（形状＋关键参数）**：按 [EE] EyeConfig 参数体系描述：`高/宽`（px）、`斜上/斜下`（斜率，正=向鼻子方向下压）、`圆上/圆下`（圆角半径 px）、`偏x/偏y`（瞳孔整体偏移 px）。形状用一句话描述。
- **动作（位移、时长、节奏曲线）**：用 [EE] Animations.h 的曲线词汇：`Ramp`（线性渐变）、`Triangle`（三角波往返）、`Trapezium`（含保持段的梯形）、`Pulse`（脉冲）。过渡统一 500ms Ramp，除非另注。
- **优先级 / 打断规则**：见下方阶梯与代号。

**优先级阶梯（[自定]）**

| 级 | 含义 | 例子 |
|---|---|---|
| P0 | 交互状态（独占） | 在听 / 在想 / 在说 / 升级 / 致命错误 |
| P1 | 系统事件 | 唤醒应答、睡眠/醒来、低电、断连、提醒 |
| P2 | 情绪表达 | 18 情绪、被显式触发的表情函数、娱乐动画 |
| P3 | 装饰叠加（常开） | 眨眼、扫视、微动、视线漂移（含待机基准） |
| P4 | 渲染原语 | draw_eyes 一类，不参与调度 |

**打断规则代号（[自定]）**

- **R-A**：可被 P0/P1 抢占；同层不互相打断（先到先演完）；被抢占走 500ms 过渡。
- **R-B**：叠加层，不打断任何层；被 P0 状态抑制（如"在听"时停扫视）。
- **R-C**：抢占所有低层；同级新态优先；退出后恢复被压层。
- **R-D**：随宿主，不做独立调度；宿主被打断则一并中止。
- **R-E**：不可打断（演到自然结束），仅 P0 例外。
- **R-F**：原语，不参与调度。

**覆盖核对（完整性声明）**：desk-emoji 全仓库核对——uno_r3 v1.0.0（robot_base）、uno_r4 v1.2.0、esp32 v1.0.0–v1.2.0、esp32s3 v1.1.0–v1.2.0、test.all、v2.0.1：眼睛函数均同一套 13 个（test.all / v2.0.1 另含 emoji_init）；屏幕动画集共 42 个（esp32 与 esp32s3 自 v1.2.0 起、v2.0.1 相同）。本表按 v2.0.1 枚举，其余版本无额外表情项。

3. **Alt 左右不对称（7 组）保留否** —— 建议保留，是"活"的关键；代价是两组参数要分别调。
4. **42 个屏幕动画留哪些** —— 需按 Sammy 屏幕尺寸重绘（desk 是 64×64）；建议先上 thinking / battery / alarm / wifi / wait / ok / heart / love 8 个。
5. **睡眠触发阈值**（建议 120s；夜间时段可叠加）与唤醒方式（唤醒词 / 手势 / 定时）。
6. **点头/摇头/翻滚的幅度与步延**：直接沿用 desk 参数，还是按 Sammy 舵机重新定。
7. **手势传感器上不上**（PAJ7620 或替代）——上了才有第 8 节那套互动。
